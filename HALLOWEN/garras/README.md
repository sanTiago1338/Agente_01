# TIAGO — Garras, sangre y fondo de horror V2

Mejora del kit anterior. No reemplaza tu tienda ni cambia sus imágenes.

Incluye:
- Fondo nuevo con pasillo, paredes húmedas, rostros insinuados y una silueta distante.
- Sombras laterales y dos capas de niebla lenta.
- Aparición de pelo largo de ocho poses, ocasional y detrás del contenido.
- Garras alrededor del título y sangre que escurre por el fondo.
- Coordinador de pausa, pestaña oculta y movimiento reducido.

Abre VER.html para probar el ambiente aislado. La aparición comienza unos segundos después; puedes pausar todo o reproducir el evento de garras/sangre. Entrega esta carpeta a Claude Code y sigue PROMPT-CLAUDE-CODE.md para integrarlo en el código real.

Es CSS/JavaScript con PNG: no video ni GIF. El personaje reproduce las poses existentes; las garras se desplazan y rotan como imágenes, sin articulación individual de dedos; la sangre se revela desde una textura. La calidad visual y los offsets finales deben comprobarse dentro de la tienda.

Archivos:
assets/: fondo.png, garra.png, sangre.png, aparicion-sprite.png
src/: efecto.css/js, terror-sprite.css/js, ambiente.css/js
VER.html: demo independiente
PROMPT-CLAUDE-CODE.md: integración completa
VALIDACION.txt: comprobaciones y límites

No se modificó ni publicó la web real. El kit anterior sigue disponible en su carpeta original.
